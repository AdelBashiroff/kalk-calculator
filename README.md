# Kalk — калькулятор, на который приятно нажимать

Минималистичный лендинг с рабочим калькулятором. Чистые HTML, CSS и JS, без зависимостей.

- тактильные кнопки, которые продавливаются при нажатии
- собственный парсер выражений (без `eval`), проценты, смена знака
- живой предпросмотр результата и лента вычислений
- ввод с клавиатуры, 4 цветовые темы, опциональный звук

Запуск: открыть `index.html` или `python3 -m http.server`.
